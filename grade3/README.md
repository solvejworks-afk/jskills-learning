# JSkills Grade 3 — Realistic External Simulation + 20-Question Quiz

Flow:
School Login → Grade 3 → Subject → Chapter/Topic → external educational activity → 20 topic-specific questions → mastery → teacher matrix.

External activities are mapped at the individual topic level, not at the subject level.

External resources used in this prototype:
- GeoGebra: elementary mathematics applets.
- British Council LearnEnglish Kids: child-friendly games/activities.
- National Geographic Education: observation/nature activities.
- US EPA Recycle City: waste/recycling games.

Because third-party sites may block iframe embedding, every topic also has an **Open in new tab** fallback.

The 20-question engine is topic-specific and uses a small realistic question bank expanded into 20 questions for each demo topic. For production, replace the demo banks with a curriculum-reviewed assessment bank and item metadata (competency, difficulty, answer, explanation).

This prototype keeps the existing JSkills teacher workflow: results → 10-student matrix → Remedial / Developing / Grade-level / Advanced → teacher intervention.

Curriculum note: this is a Grade 3 prototype based on the current NCERT/CBSE-aligned structure; validate every chapter and external activity against the exact academic-year board syllabus before school deployment.
