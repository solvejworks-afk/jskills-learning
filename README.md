# JSkills Learning — School Demo v4

This prototype demonstrates the proposed school workflow:

Login → School Category → Grade 3–12 → Subjects → Interactive Simulation → 20-question Assessment → Online MCQ / OMR Answer Sheet → 10-student Assessment Matrix → Remedial / Advanced Pathways.

## Demo details
- Demo school defaults to **ABC School**
- Choose **Matriculation** or **CBSE**
- Grades 3–12
- Core subjects: English, Science, Mathematics, Social Science
- Senior subjects: Physics, Chemistry, Botany, Zoology
- One interactive simulation concept for each core subject
- Grade 7 includes **NEET Basics / Foundation** option
- 20-question assessment for each subject
- Printable/viewable OMR answer sheet
- OMR upload placeholder for future automated scanning
- Cohort assessment matrix for 10 demo students
- Remedial / Developing / Grade-level / Advanced classification
