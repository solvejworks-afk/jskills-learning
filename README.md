# JSkills Quest — Gamified Learning Demo v3

GitHub Pages-ready static prototype.

## Demo concept
JSkills combines:
- Simulation-based learning
- Adaptive practice
- Gamification: XP, levels, streaks, coins, missions and badges
- Competency diagnosis
- Remedial intervention
- Olympiad Foundation
- NEET Foundation
- School analytics

## Upload
Replace the files in the existing GitHub repository with:
- index.html
- styles.css
- script.js
- README.md

Then GitHub Pages will automatically publish the new version.
