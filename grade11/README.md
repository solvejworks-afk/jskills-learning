# JSkills Grade 11 — CBSE + NEET Foundation

Flow:
School Login → Grade 11 → English / Physics / Chemistry / Biology / Mathematics → topic → external activity → 20-question assessment → mastery → CBSE academic support / NEET Foundation → teacher matrix.

Grade 11 demo topics:
- English: Argument, synthesis and evidence-based writing
- Physics: Motion in a straight line — graphs and kinematics
- Chemistry: Mole concept and stoichiometry
- Biology: Cell structure and organelle functions
- Mathematics: Functions and graphical relationships

NEET Foundation Level 6:
- Physics — mechanics, properties of matter, thermodynamics and quantitative problem solving
- Chemistry — mole concept, atomic structure, bonding, thermodynamics and reaction reasoning
- Botany — cell biology, plant anatomy, morphology and physiology
- Zoology — animal tissues, structural organisation and human physiology foundations
- Scientific Reasoning — experimental design, graphs, units, data interpretation and error analysis

Grade 11 prioritises school/CBSE mastery while providing a separate diagnostic foundation layer for students considering the NEET pathway. It is not formal NEET coaching and does not predict NEET rank.

External activities are topic-specific. A direct external link is provided if iframe embedding is blocked.
