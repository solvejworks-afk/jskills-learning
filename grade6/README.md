# JSkills Grade 6 — CBSE + NEET Foundation

Core demo:
School Login → Grade 6 → English / Mathematics / Science / Social Science → topic → external learning resource → 20 questions → mastery → teacher matrix.

Grade 6 topics:
- English: reading, main idea, evidence and vocabulary
- Mathematics: integers and number-line operations
- Science: cells, tissues and biological organisation
- Social Science: latitude, longitude and map skills

NEET Foundation:
An optional Grade 6 early-science pathway covering Biology, Chemistry, Physics and Scientific Reasoning. It is explicitly a foundation/talent-identification layer, not a claim of NEET preparation at Grade 6.

CBSE/NCERT note:
NCERT lists Grade VI books including Ganita Prakash, Poorvi, Curiosity and Exploring Society: India and Beyond. CBSE also provides competency-based learning frameworks for Science, Mathematics and English. Session 2026-27 makes Kaushal Bodh mandatory for Classes VI-VIII. These references informed the structure, but each topic should be mapped to the school's exact adopted textbook and academic-year sequence before deployment.
